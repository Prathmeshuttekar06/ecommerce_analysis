# 📊 E-Commerce Sales & Profit Analysis Dashboard

## 📌 Project Overview
This project showcases an interactive Power BI dashboard built on top of a MySQL database with 9 tables. It provides insights into sales, revenue, profit, customer behavior, and returns for an e-commerce business.

---

## 🛠️ Tech Stack
- **Database:** MySQL (Customers, Orders, Products, Categories, Payments, Returns, etc.)
- **Visualization:** Power BI
- **Data Modeling:** DAX measures and relationships
- **Languages:** SQL, DAX

---

## 📈 Key Features
- **KPIs:**
  - Total Revenue
  - Total Orders
  - Average Order Value (AOV)
  - Gross Profit
  - Profit Margin

- **Interactive Filters & Slicers:**
  - Category Name
  - Customer ID
  - Order Date

- **Visuals:**
  - Revenue Trend (Line Chart)
  - Top Products by Revenue (Bar Chart)
  - Payment Method Distribution (Pie Chart)
  - Returns Analysis (Stacked Column Chart)

---

## 🔍 Insights
- Electronics and Automotive categories drive the highest revenue.
- Majority of payments are completed through online methods.
- Returns are mostly due to late delivery, highlighting operational improvement areas.
- Repeat customers contribute significantly to overall revenue.

---

## 🚀 How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/Prathmeshuttekar06/ecommerce_analysis.git
   ```
2. Open the MySQL database and import the ecommerce schema.
3. Run the SQL queries in `queries.sql` to validate key business metrics.
4. Open the Power BI dashboard file (`ecommerce_analytics.pbix`) to explore the report.
5. Use the slicers and filters to view revenue and profitability by category, date, and customer.
